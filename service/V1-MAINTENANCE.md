# V1 Maintenance
Volunteer: inspect outlet, wipe exterior with approved cleaner, reload paper, report error code; no cash access.
Cash collector: separate key, swap/remove cassette; no electronics access.
Technician: replace printer/controller/display/sensor/PSU, update signed firmware/content and run diagnostics.
Targets: printer/controller/display/sensor <10 minutes; PSU <5 minutes; no field soldering.
Starting spares per 100 deployed: 5 printers, 5 PSUs, 3 controller boards, 3 displays, 5 lock sets, 10 sensor modules, 3 harnesses.
