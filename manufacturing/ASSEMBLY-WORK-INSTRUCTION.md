# Assembly Work Instruction — Draft
1. Verify chassis lot and finish.
2. Install PEM hardware / anchors.
3. Install cash chute and cassette guides.
4. Perform chute go/no-go gauge inspection.
5. Install cash and service locks; verify distinct access.
6. Install printer bracket and printer.
7. Install display and front bezel.
8. Install controller PCB and harness.
9. Install sensors and confirm mechanical actuation.
10. Install PSU inlet/low-voltage connector assembly.
11. Optional battery module.
12. Flash factory firmware and device identity.
13. Run EOL automated fixture.
14. Load production firmware and signed content bundle.
15. Security fastener torque witness marking.
16. Cosmetic inspection and clean.
17. Pack approved paper starter roll separately unless shipping rules permit installed roll.
18. Final serial scan and carton seal.
