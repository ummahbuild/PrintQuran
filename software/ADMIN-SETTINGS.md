# Admin Settings
Protected by service authentication, not exposed on public screen.

Configurable:
- translation language/edition.
- transliteration resource/style.
- Arabic renderer/font profile.
- translation/transliteration fonts.
- font-size presets (tested bounds only).
- line spacing.
- donor language selector on/off.
- preset NFC donation amounts/currency.
- max uses per day / operational hours if deployment requires.
- paper-saving mode.
- max physical part length.
- QR footer.
- network/fleet connection.

Not configurable without a signed content release:
- arbitrary Arabic text editing.
- āyah numbering.
- sūrah order.
- canonical text source.
