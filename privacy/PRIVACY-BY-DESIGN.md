# Privacy by Design
Public output is based on Qur’an progression, not donor activity.

Public-safe examples:
- 47 complete Qur’ans printed.
- current Qur’an #48.
- current sūrah 18/114.
- āyāt printed in current Qur’an according to dataset.

Not public:
- donation amount.
- number of donations/donors.
- latest donation time.
- card/cash mix.
- payer identifiers.

Cash detector should generate only a donation event. Payment provider accounting remains separated from public progress UX.
