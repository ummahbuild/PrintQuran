# DIY V1 Build Guide
1. Buy ESP32-S3 dev board, qualified 80 mm 203-dpi cutter printer, certified low-voltage PSU and phenol-free paper.
2. Measure actual printer dots per line and calibrate density/cutter.
3. Render reviewed Arabic to monochrome bitmap; add ayah marker and optional approved translation/transliteration.
4. Implement atomic print state and pull power during every state to prove resume.
5. Use a button as simulated donation trigger.
6. Add two optical sensors and a baffled prototype chute.
7. For real money, use a purchased lockable steel cash box; do not use printed plastic as a safe.
8. Keep service and cash physically separated, anchor enclosure, then commission privacy/content/print tests.
