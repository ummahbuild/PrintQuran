# Presets and Setup
Configuration = country pack + institution preset + donation mode + approved print profile + detected hardware + privacy + maintenance.

Wizard: country -> donation mode -> public language -> approved print profile -> printer test -> trigger test -> privacy check -> anchor/commission.

Modes: Cash Only, Manual Staff, Envelope, Tap Only, Cash+Tap, Existing Donation System, Sponsored, Education, Demo. Cash Only hides payment menus, has no amount selector, needs no network and never estimates denomination.

Country packs may suggest currency formatting, timezone, UI languages, power lead and optional payment adapters, but must never silently choose religious content.
